# Department of Computing Website — SWD414

A responsive four-page demonstration website created for the SWD414 assignment on Version Control, Git and GitHub.

## Pages
- `index.html` — Homepage
- `about.html` — About the department
- `programmes.html` — Illustrative programme list
- `contact.html` — Contact details and demonstration form

## Run the website
Open `index.html` in a web browser. No build tools are required.

## Important customisation
Before submission, replace the sample email, institution name/location, and illustrative programmes with accurate information from your institution. The contact form is front-end only and does not send email.

## Git workflow demonstrated
The repository includes a local Git history with an initial setup commit, a homepage improvement commit, a Contact Us feature branch and merge, and a final update commit. See `REPORT.md` for the commands and explanation.

## Publish to your GitHub account
1. Create an empty repository on GitHub (do not initialise it with a README).
2. In this project folder, run:
   `git remote add origin https://github.com/YOUR-USERNAME/swd414-department-of-computing.git`
3. Run:
   `git push -u origin main`
4. Run:
   `git push origin --all`
5. Open the GitHub repository in your browser and confirm the files and commit history are visible.
